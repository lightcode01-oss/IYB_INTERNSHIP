# Data directory

uci_student_performance.csv is the public UCI ID 320 dataset, cached from its official data.csv endpoint. Attribution and license are in docs/DATA_AND_MODEL_CARD.md. demo_input.csv contains three public demonstration predictor records. Neither file contains added private student records.

data/monitoring is local-only and ignored by Git. Do not copy personal uploads, event logs or batch exports into version-controlled files.
